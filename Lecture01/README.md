## Objective

This assignment demonstrates how to generate, visualize, and interpret
simple signals using MATLAB.

## Tasks

### Task 1: Create a Sine Wave

A sine wave with an amplitude of 1 and a frequency of 5 Hz
was generated for a duration of 1 second.

### Task 2: Compare Different Frequencies

Three sine waves with frequencies of 2 Hz, 5 Hz, and 10 Hz
were generated and displayed using subplots.

#### Questions

1. Which signal changes fastest?

The 10 Hz signal changes fastest because it completes the most
cycles per second.

2. Which signal has the lowest frequency?

The 2 Hz signal has the lowest frequency.

3. How can you see the difference in the plots?

The higher-frequency signals have more cycles within the same
one-second interval.

### Task 3: Compare Different Amplitudes

Three sine waves with amplitudes of 0.5, 1, and 2 were generated
using the same frequency.

#### Questions

1. Which signal has the largest amplitude?

The signal with an amplitude of 2 has the largest amplitude.

2. Does changing amplitude change frequency?

No. Changing amplitude changes the height of the signal,
but it does not change its frequency.

3. Give one real-world example where amplitude is important.

In an audio signal, amplitude is related to the strength of the sound.
A larger amplitude generally represents a louder sound.

### Task 4: Add Noise

Random noise was added to a clean sine wave.

#### Questions

1. What changed after adding noise?

The signal became less smooth because random variations were
added to the original sine wave.

2. Can you still recognize the original signal?

Yes. The original sine-wave pattern can still be recognized,
although the signal is more irregular.

3. Give one real-world source of signal noise.

Electrical interference from nearby electronic devices can
introduce noise into a sensor signal.
